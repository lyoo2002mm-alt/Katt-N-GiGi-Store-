# Katt's Store APK project

This Android WebView wrapper opens the public Katt's Store site:
https://kattandgigistore.netlify.app

Package: com.kattandgigi.store

The included GitHub Actions workflow builds an unsigned release APK automatically.

## App icon
The APK launcher icon is the provided Katt + GiGi Store artwork. It is included in the mipmap density folders and as an adaptive icon for Android 8.0+.
